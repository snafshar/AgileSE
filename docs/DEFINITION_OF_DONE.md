## Definition of Done

A small software-engineering increment is complete when:

1. The user-visible behavior is described in one sentence.
2. The implementation is separated from presentation concerns.
3. Invalid input has an explicit outcome.
4. A happy-path example exists.
5. A regression test covers the important boundary.
6. The change is documented close to the code.
7. The project still builds from a clean checkout.

This checklist is intentionally lightweight so it can be applied to desktop, web, and command-line slices.
