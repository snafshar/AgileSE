# Definition of Done

A backlog item is considered done when the agreed criteria below are met or an explicit exception is recorded.

- [ ] Acceptance criteria are satisfied.
- [ ] Code has been reviewed by another contributor where practical.
- [ ] Relevant automated tests pass.
- [ ] New behavior and known limitations are documented.
- [ ] Errors and boundary cases have been considered.
- [ ] Accessibility, privacy, and security implications are reviewed where applicable.
- [ ] No credentials or sensitive test data are committed.
- [ ] The change can be built or run from a clean checkout.
- [ ] Monitoring or rollback steps are included for operationally risky changes.
- [ ] The product owner or delegate accepts the result.

Teams should adapt this checklist to the product rather than treating every line as equally relevant to every change.
