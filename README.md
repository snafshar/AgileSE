# Agile Software Engineering Projects

I use this repository to practise iterative product development: user stories, acceptance criteria, vertical slices, testing, and retrospectives.

## Projects

- `focusdesk-core` — desktop focus-planner domain model
- `sprint-board` — lightweight backlog and sprint planning model
- [Team Sprint Kit](https://github.com/snafshar/AgileSE/tree/main/labs/2026-10-19/team-sprint-kit) — product brief, sprint plan, definition of done, test strategy, risk register, and retrospective templates

## Working principles

The repository emphasizes small vertical slices: each feature should have a clear user-facing goal, acceptance criteria, and a testable domain model. Keep templates concise, tailor checklists to the product, and record follow-up actions with owners and review dates.
